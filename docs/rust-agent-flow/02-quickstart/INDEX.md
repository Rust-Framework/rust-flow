# 第二章 快速上手

本章带你从零跑起第一个流程设计器，10 分钟内看到可交互的画布。

## 本章小节

| 小节 | 内容 |
|------|------|
| [创建项目与依赖](create-project.md) | Cargo 工作区、依赖引入与目录约定 |
| [Hello World 详解](hello-world.md) | 最小窗口、FlowEditorView 与初始化 |

| [运行、调试与验证](run-and-debug.md) | 本地运行、交互验证与日志 |

## 学习目标

读完本章，你应能：

1. 创建一个依赖 rust-agent-flow-gpui 的 GPUI 应用
2. 用 FlowEditorView 显示一个可拖拽/缩放/连线的画布
3. 用 FlowDocument 数据驱动构建流程图
4. 独立运行并验证交互
